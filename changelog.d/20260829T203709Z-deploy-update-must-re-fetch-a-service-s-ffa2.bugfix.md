The chat update endpoint (`POST /chat/services/{name}/update`) now re-fetches the service's `deploy/docker-compose.yml` from its repo before recreating the container, so compose-only changes (e.g. added or edited `robotsix.deploy.*` proxy labels) are applied even when the image tag/digest is unchanged. Previously such changes never reached the running container and the proxy route was never created. Applied contract changes are surfaced in the update response and audit log.
