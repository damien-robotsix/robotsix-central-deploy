Contract refresh (`POST /services/{name}/refresh-contract` and the deploy-time re-fetch added in #819) now clones the component repo with the GitHub App installation token, like onboarding already did. Private repos previously failed with `could not read Username for 'https://github.com'` and silently kept their onboard-time contract — hexarchy (private) had `ports: []`, hence no Traefik labels and a proxy `404 page not found` on a healthy container.
