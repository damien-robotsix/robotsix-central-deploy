refresh-contract: stop reverting operator-set fields. Re-importing a component's `deploy/docker-compose.yml` rebuilt its config from the manifest alone, resetting `mem_limit`, `allow_chat_access` and `claude_mount` (all settable via `PUT /services/{name}/env`) to their label defaults, and resetting host ports to the manifest's values — which reassigned one component onto a port another already owned. Those fields are now preserved, and a container port the component already exposes keeps its assigned host port; only genuinely new ports are allocated, using the same collision preflight as onboarding.
