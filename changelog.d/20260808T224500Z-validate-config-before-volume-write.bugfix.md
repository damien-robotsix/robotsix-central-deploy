The deploy plane now validates a config document against the component's own stored schema before writing it to the component's config volume, and refuses the write on a violation. A component whose config file does not load simply crash-loops, so an invalid write previously succeeded and surfaced later as an unexplained outage — on 2026-08-08 the `fleet_auth.auth_hosts` reconciliation wrote a top-level `fleet_auth` that chat's schema does not declare, crash-looping it 13 times. Components with no stored schema are written unchecked, so onboarding is unaffected.
