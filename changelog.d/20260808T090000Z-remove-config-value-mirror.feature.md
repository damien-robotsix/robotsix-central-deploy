The deploy plane no longer keeps a copy of component config *values*. `ConfigYamlStore` loses `current`, `update_current`, `update_current_and_hash` and `get_volume_hash`; every reader now goes to the component's own config file via `read_component_config`, and the chat-agent mutation writes it directly. The deploy-time drift guard is gone with them — there is no second copy left to drift from. The schema `template` is still stored, since that is what the config UI renders.
