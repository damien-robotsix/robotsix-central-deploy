Claude Auth panel logins now request a refresh-capable OAuth scope set, so the credential written into the `claude-auth` volume can actually be auto-renewed. The panel previously requested the bare `user:inference` scope — Claude Code's `inferenceOnly` path — whose token exchange returns no refresh token. That produced an 8-hour credential nothing could renew: the background refresh loop skipped it in silence, and every component started returning `401 OAuth access token has expired` roughly 8 hours after each login, with a stale error still showing in the panel. `org:create_api_key` is deliberately not requested — this credential is mounted into every fleet component and does not need to mint org API keys.

Failures in this path are no longer silent: the login response carries a `warning` (surfaced in the dashboard) when the exchange returns no refresh token, `/claude-auth/status` reports `refresh_capable`, the refresh loop records "credential has no refresh token" as its standing error instead of skipping quietly, and a rejected refresh grant is reported as `Refresh rejected (400): ...` rather than the misleading `Token endpoint unreachable`.
