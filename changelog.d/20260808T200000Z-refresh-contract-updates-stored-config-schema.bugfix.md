`POST /services/{name}/refresh-contract` now refreshes the stored config schema. It parsed only `deploy/docker-compose.yml`, which never carries the schema, so the `save_template` branch was unreachable and every component's template stayed pinned at its onboarding version — the dashboard config editor and `PUT /chat/config/{name}` then silently dropped any key the component had added since. Schema changes are reported as a `config_schema` entry in `changed_fields`.
