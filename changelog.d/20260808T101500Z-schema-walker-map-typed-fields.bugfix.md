Config fields declared as maps (`{"type": "object", "additionalProperties": {…}}`, no `properties`) are no longer silently emptied. The shared JSON Schema walker only descended into declared `properties`, so every such field came back `{}` from all three visitors: masked reads showed an empty map, and a merge replaced the stored map with one — a silent wipe on write. `langfuse.projects.<alias>` is exactly this shape.
