Serve `/ui/static/*` with `Cache-Control: no-cache` so browsers revalidate. The assets carry no version in their URL while `/ui` is rendered fresh on every request, so with no explicit directive a browser applied heuristic caching and paired a stale `dashboard.js` with markup from a later deploy. After the AppShell adoption that mismatch meant a cached pre-AppShell `dashboard.js` — whose `updateRefreshTime` was still unguarded — ran against markup that no longer carried the static `<header>`, producing `Dashboard error: can't access property "textContent", document.getElementById(...) is null` until the operator hard-refreshed. The ETag makes each revalidation a cheap 304.
