Deploy no longer writes the deploy-plane's stored copy of a component's config over the component's own config file. It seeds the shipped template only when the config volume is empty, and never overwrites an existing file. Previously the drift guard only protected a volume when a stored `volume_hash` existed *and* differed, so a component whose config had never been saved through the deploy UI had its live config replaced by the stored copy on every deploy — which is how chat's Langfuse credentials were replaced by an empty pre-migration block on 2026-08-07 and dropped out of fleet-wide Langfuse discovery.
