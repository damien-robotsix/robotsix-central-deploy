Fix the dashboard header rendering as literal HTML source. `mountAppShell` inserts a **string** `rightSlot` with `textContent` and only a **Node** with `appendChild`, so the markup central-deploy passed was escaped rather than parsed: the Add Component / Claude Auth / Update server / Logout buttons and the `refresh-time` span were painted as visible source text and never entered the DOM. Every `dashboard.js` lookup for one then resolved to `null`, surfacing as `Dashboard error: can't access property "textContent", document.getElementById(...) is null` and leaving the self-update check permanently broken. The shell now parses the markup into a `<template>` fragment and hands `mountAppShell` a real Node.
