## [0.5.0](https://github.com/damien-robotsix/robotsix-central-deploy/compare/v0.4.0...v0.5.0) (2026-08-09)


### ⚠ BREAKING CHANGES

* **edge:** components no longer answer to HTTP Basic at the edge, and deploy/traefik/fleet-users is unused. robotsix-chat's http_probe/public_fetch against *.deploy.robotsix.net will receive the SSO redirect instead of the component until they are pointed at internal container addresses.
* **edge:** GATEWAY_BASE_DOMAIN is now required in .env, and deploy/traefik/traefik.yml is gone. Existing deployments must add the variable before the next `docker compose up -d`.

## [0.4.0](https://github.com/damien-robotsix/robotsix-central-deploy/compare/v0.3.0...v0.4.0) (2026-08-09)


### ⚠ BREAKING CHANGES

* components are no longer proxied by central-deploy and are served by Traefik at <id>.<gateway_base_domain>. Deployment now requires the traefik, traefik-socket-proxy and tinyauth containers, an OVH API credential for the ACME DNS-01 wildcard (the same one certbot used), and a relabel pass redeploying each component so it receives its routing labels. The rate_limit_login_per_minute, rate_limit_login_max_attempts and rate_limit_login_lockout_seconds settings are removed.

The panel previously requested the bare `user:inference` scope — Claude Code's `inferenceOnly` path — whose token exchange returns no refresh token. That produced an 8-hour credential nothing could renew: the background refresh loop skipped it in silence, and every component started returning `401 OAuth access token has expired` roughly 8 hours after each login, with a stale error still showing in the panel. `org:create_api_key` is deliberately not requested — this credential is mounted into every fleet component and does not need to mint org API keys.

  Failures in this path are no longer silent: the login response carries a `warning` (surfaced in the dashboard) when the exchange returns no refresh token, `/claude-auth/status` reports `refresh_capable`, the refresh loop records "credential has no refresh token" as its standing error instead of skipping quietly, and a rejected refresh grant is reported as `Refresh rejected (400): ...` rather than the misleading `Token endpoint unreachable`. (claude-auth-refresh-token)

  exponential-backtracking ReDoS in the caret, tilde, betterem and magiclink inline
